# SkyPlan

SkyPlan is an activity planner app. Users pick a location and a date, and the app suggests activities based on the weather forecast for that place and time. As the forecast changes, the suggested activities adapt accordingly, giving the user an up-to-date list of things they can actually do.

## Status

Early stage — base Flutter project scaffolded for iOS and Android. Core features are not implemented yet.

## Tech stack

- [Flutter](https://flutter.dev) / Dart
- Target platforms: iOS, Android

## Getting started

```bash
flutter pub get
flutter run
```
